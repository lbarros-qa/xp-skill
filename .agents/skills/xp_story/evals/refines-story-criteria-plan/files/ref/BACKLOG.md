# Backlog

## Context

A personal analytics dashboard for individual users.
Stack: Node.js with TypeScript, Vitest for tests
Expensive decisions: single-tenant, English-only UI

## Stories

1. As a user, I want to see my weekly activity summary on the dashboard, so that I can track how I am doing.
2. As a user, I want to switch between light and dark themes, so that I can use the dashboard comfortably in low-light environments.
3. As a user, I want the selected theme to persist across sessions, so that I do not have to change it every time I open the app.
